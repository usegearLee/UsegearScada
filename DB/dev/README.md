# 未加密开发数据库

`usegear_dev.db` 是供本项目开发和测试使用的空库，由 `python DB/design/create_dev_db.py` 创建。它不会复制、解密或修改同级目录下现有的加密 `usegear.db`。

目前开发库包含旧菜单表迁移和工程对象模型候选表，仅用于原型验证。`core_model_v0_1.sql` 仍是候选设计，尚未在正式加密库中应用。应用程序目前是否已切换到此库**未验证**；连接切换和加密库兼容性仍需通过 Delphi/uniGUI 工程及其实际数据库驱动检查。

开发库只放虚构测试数据。正式环境仍需用同一套迁移验证加密库的创建、升级、备份与恢复。开发库文件不应当作生产数据库发布。
