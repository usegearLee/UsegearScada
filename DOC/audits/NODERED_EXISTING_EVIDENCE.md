## 对新产品模型的直接影响

- 工程配置需要表达设备、Tag、协议、采集周期、地址、数据类型、来源、质量和稳定标识；具体字段及值域必须按模板参数契约再核实。
- SQLite 工程配置库与 Node-RED 运行期 SQLite 缓存是两套不同的数据职责，不应混用路径或表。
- 缓存和转存需作为明确的项目运行模式配置。无 PG 模式的界面不能显示“已完成转存”；PG 不可用的行为由运行模板验证决定。
- 原候选中的协议驱动版本和自有读取门控有依赖约束；不能只生成 Flow JSON 就宣布可在任意 Node-RED 实例安全运行。
- Node-RED 的受管 Flow 边界、部署版本、备份与停止确认必须进入项目运行管理；从历史文档不能推定现场实例就是已测试版本。
